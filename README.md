## About This Project

This repository contains the official website for **Auntyant Creative**, a visual design studio focused on branding, graphic design, content creation and social media systems.

The website is designed to present the studio with a more editorial, creative and premium visual identity while remaining lightweight, responsive and easy to maintain.
